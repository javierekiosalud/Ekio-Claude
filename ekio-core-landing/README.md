# PDP Ekio Light Core — Paquete completo

Ficha de producto (PDP) del **Ekio Light Core — dispositivo portátil de fotobiomodulación local** (entrada de gama de EKIO Light), construida con el mismo formato que las PDP de Deep 5, Bio Regen 7 y Bio Spectrum 11.

**Precio:** ~~175 €~~ **147 € (oferta de lanzamiento)**. Es el dispositivo de entrada de la gama Ekio Light: local y portátil (no cuerpo completo), 13 LEDs de chip dual (660 nm rojo + 850 nm infrarrojo cercano), batería recargable USB-C.

Ensamblado a partir de 4 capas de trabajo especializado:
- **Contenido** → copy narrativo y persuasivo, incluida la estructura de conversión (buy box, comparativa, objeciones)
- **SEO** → keywords, meta, headings, enlazado on-page (Google)
- **GEO** → JSON-LD, frases citables, Q&A y llms.txt (ChatGPT, Claude, Gemini, Perplexity, AI Overviews)
- **Visual** → `index.html` navegable con ilustración interactiva del dispositivo, buy box, sticky bar y bloques CRO

Fuente única de verdad: `Content/landings/landing-core.md` (landing ya validada por Javier con specs del fabricante — precio actualizado el 15-jul-2026 de 140 € fijo a oferta 175 €→147 €).

## Cómo usar este paquete
1. Empieza por **`02-COPY-COMPLETO.md`** — es el documento maestro con los bloques de la PDP.
2. **`01-SEO-STRATEGY.md`** + **`01-SEO-keywords.csv`** — metadatos y on-page para Google.
3. **`01-schema-product.json`** — pegar en el `<head>` (Product + FAQPage + BreadcrumbList).
4. **`03-GEO-CITABILIDAD.md`** — frases citables, Q&A IA, entrada llms.txt, comparativa, E-E-A-T.
5. **`05-INSTRUCCIONES-IMPLEMENTACION.md`** — datos de Shopify, orden de bloques y checklist de publicación.
6. **`index.html`** — versión visual navegable, verificada en navegador (ilustración interactiva del dispositivo con 4 modos, tabla de especificaciones, comparativa de gama, FAQ y sticky bar).

## Diferencia con los paneles (Deep 5 / Bio Regen 7 / Bio Spectrum 11)
El Core **no es un panel**: es un dispositivo local y portátil con batería, pensado para tratar una zona concreta (rodilla, cuello, hombro, cara, pies/manos) en cualquier sitio. No compite por las mismas keywords que los paneles de cuerpo completo — es la puerta de entrada de precio más bajo de la gama y el único producto portátil.
