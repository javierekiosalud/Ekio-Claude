# SKILL — pbm-estudio-formacion (Estudio y Formación del Equipo)
> Convierte la ciencia PBM en aprendizaje para Javier y su equipo: explicaciones, fichas, quizzes, glosario, rutas.

## Cuándo usarla
"Explícame…", "ayúdame a estudiar…", "forma a mi equipo en…", fichas de repaso, examen/quiz, glosario, plan de aprendizaje.

## Modos

### 1. EXPLICACIÓN DIDÁCTICA (3 niveles)
Explica el mismo concepto en: **(a) 1 frase** · **(b) analogía cotidiana** · **(c) profundidad técnica con mecanismo y fuentes**. Marca el tier de lo que no esté establecido.

### 2. FICHAS DE REPASO / ANKI
```
P: [pregunta]
R: [respuesta concisa]  (tier si aplica)  [fuente]
```
Genera lotes temáticos (cromóforos, ventanas, dosimetría, investigadores, nexo CEM).

### 3. QUIZ / EXAMEN
Preguntas tipo test + abiertas, con solucionario explicado. Niveles: básico (vendedor/atención cliente) · medio (marketing/contenido) · avanzado (I+D/Javier).

### 4. GLOSARIO
Término → definición clara → por qué importa para Ekio. (CcO, ΔΨm, fluencia, irradiancia, hormesis, Nrf2, tPBM, MED, fototipo Fitzpatrick…)

### 5. RUTA DE APRENDIZAJE
Plan por roles del equipo:
- **Atención cliente / ventas:** fundamentos, los 3 paneles, seguridad, objeciones frecuentes.
- **Marketing / contenido:** mecanismos clave, nexo CEM, evidencia citable, Regla 5.
- **I+D / Javier:** dosimetría avanzada, papers, frontera (Jeffery, Cassano), IP.

## Principio
Enseña con honestidad de evidencia: el equipo debe saber distinguir 🟢 de 🔴 para no sobre-prometer ante clientes. Usa `pbm-evidencia` para anclar y `notebooklm` para el corpus interno.
