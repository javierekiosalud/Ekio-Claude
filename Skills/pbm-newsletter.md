# SKILL — pbm-newsletter (Newsletters Científicas)
> Newsletters PAS con rigor científico + voltaje Ekio, listas para Klaviyo.

## Cuándo usarla
"Newsletter sobre…", email científico/educativo, secuencia formativa por email.

## Insumos a pedir/definir
Tema · ángulo (problema CEM / λ / condición / producto) · segmento · objetivo (educar/vender/reactivar) · CTA · panel a destacar.

## Proceso
1. Funda con `pbm-evidencia` (mínimo 2-3 fuentes reales con tier).
2. Estructura **PAS** + ADN Ekio. Aplica Regla 5 (bienestar).
3. Opcional: preparar en Klaviyo vía MCP (confirmar antes de publicar).

## Estructura
```
ASUNTO: [<50 car, dato/curiosidad/tensión]   PREVIEW: [complementa, no repite]
1. HOOK — dato científico real y verificado (con fuente)
2. PROBLEMA — CEM / déficit de luz / condición, con cifras y estudio
3. AGITACIÓN — mecanismo molecular explicado con potencia (pero honesto)
4. CONEXIÓN MTC (si suma)
5. SOLUCIÓN — Ekio Light: mecanismo + evidencia + tier
6. PROTOCOLO PRÁCTICO — cómo usar el panel (resumen, sin sobre-prometer)
7. SINERGIAS — suplementación/nutrición/aromaterapia/fitoterapia
8. CTA — específico y urgente
P.D. — gancho de refuerzo
```

## Estilo
Frases cortas, segunda persona, alto voltaje, autoridad científica. Citas integradas naturalmente ("un estudio de Harvard en 2018…"). Nunca aburrido, nunca claim ilegal.

## Checks
- [ ] Hook con dato verificable.  [ ] ≥2 fuentes reales con tier.
- [ ] Lenguaje de bienestar (Regla 5).  [ ] Nexo CEM si aplica.  [ ] 1 CTA claro.
- [ ] Asunto <50 car. Sin promesas médicas.
