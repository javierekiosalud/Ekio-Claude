# SKILL — pbm-blog (Artículos de Blog SEO/GEO)
> Artículos largos, científicos y optimizados para Google + motores IA (ChatGPT, Claude, Gemini, Perplexity, AI Overviews).

## Cuándo usarla
"Artículo de blog sobre…", contenido pilar/cluster, SEO científico, posicionar una λ o condición.

## Proceso
1. **Keyword + intención** (informacional/transaccional). Define keyword principal + secundarias + preguntas (People Also Ask).
2. Funda con `pbm-evidencia` (un artículo pilar cita 5-10 fuentes con tier).
3. Redacta long-form (1.500–2.500+ palabras) con estructura escaneada.
4. GEO: respuestas directas y citables, datos concretos, definiciones limpias (lo que las IA extraen).
5. Schema: sugiere `Article` + `FAQPage` (+ `MedicalWebPage` solo si procede legalmente).

## Estructura
```
H1: [keyword + ángulo]
Intro (50-100 palabras): respuesta directa a la intención (citable por IA)
H2: ¿Qué es / por qué importa?  (definición limpia)
H2: La ciencia (mecanismo + evidencia con tier y citas)
H2: Nexo electrosmog ↔ luz (diferencial Ekio)
H2: Aplicación práctica / protocolo resumido
H2: Producto Ekio recomendado (natural, no forzado)
H2: FAQ (4-6 preguntas reales → respuestas de 40-60 palabras, schema FAQPage)
Conclusión + CTA
---
META TITLE (<60c) · META DESCRIPTION (<155c) · SLUG · keywords · enlaces internos sugeridos · JSON-LD schema
```

## GEO/AEO (citabilidad por IA)
- Primera frase de cada sección = respuesta autónoma.
- Datos con fuente y año (las IA priorizan lo verificable).
- Listas y tablas (fáciles de extraer).
- E-E-A-T: autoría, citas, tier de evidencia visible.

## Checks
- [ ] Keyword en H1, intro, ≥1 H2, meta.  [ ] 5+ fuentes con tier.
- [ ] FAQ con schema.  [ ] Lenguaje legal (Regla 5).  [ ] Enlaces internos a producto/otros posts.
- [ ] Coordinar con `seo-agent` si hay que publicar en Shopify.
