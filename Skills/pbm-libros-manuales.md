# SKILL — pbm-libros-manuales (Long-form, Manuales, Apps)
> El nivel de máximo rigor: capítulos de libro, manuales de uso de los paneles y contenido para apps/SFPA.

## Cuándo usarla
"Capítulo de libro", "manual de uso del Deep 5/Bio Regén 7/Bio Spectrum 10", "contenido para la app", documentación técnica de cliente o interna.

## Principio rector
Aquí el rigor es **máximo** y el lenguaje legal **crítico** (un manual es documento de producto). 🔴 los marcos teóricos (EZ water, biofotones, electrobiofotónica, SRBA) se omiten o se etiquetan claramente como "marco conceptual / línea de investigación", nunca como hecho. Funda todo con `pbm-evidencia`.

## A) CAPÍTULO DE LIBRO
```
- Título + promesa del capítulo
- Apertura narrativa (caso/dato)
- Desarrollo: concepto → mecanismo → evidencia (con citas + tier) → matices/controversias
- Cuadros: "La ciencia en breve", "Mitos vs evidencia"
- Aplicación práctica + protocolo
- Cierre + puente al siguiente capítulo
- Referencias (formato académico, APA + DOI)
```
Tono: divulgación de autoridad (estilo Rhonda Patrick / Huberman en español), riguroso pero legible.

## B) MANUAL DE USO DE PANEL
```
1. Bienvenida + qué es la fotobiomodulación (1 párrafo claro)
2. Especificaciones del panel (λ, potencia, área) — ver references/pbm-productos.md
3. Seguridad PRIMERO: contraindicaciones, protección ocular, fototipo (si UV), embarazo, fármacos fotosensibles
4. Cómo usar: distancia, tiempo, frecuencia, hormesis ("más no es mejor")
5. Guía rápida por objetivo de bienestar (tabla)
6. Mantenimiento y garantía
7. Disclaimer legal de bienestar (NO producto sanitario salvo CE)
8. Preguntas frecuentes
```
⚠️ Cada indicación en lenguaje de **bienestar/apoyo**. Sin promesas médicas.

## C) CONTENIDO APP / SFPA
Microcopys, fichas por λ, recomendaciones personalizadas (basadas en objetivo del usuario), explicaciones in-app de protocolos. Mismo rigor; formato modular y breve.

## Checks
- [ ] Cada claim con fuente + tier; 🔴 etiquetado o eliminado.
- [ ] Seguridad y contraindicaciones completas (en manual: antes que beneficios).
- [ ] Lenguaje legal impecable (Regla 5).  [ ] Referencias en formato académico.
- [ ] Coherencia con `references/pbm-productos.md`.
