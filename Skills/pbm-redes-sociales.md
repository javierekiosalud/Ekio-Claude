# SKILL — pbm-redes-sociales (Reels, Carruseles, Posts)
> Contenido social científico de alto voltaje: Reels (estructura 2-Reel), carruseles (método Fede Cabral), posts.

## Cuándo usarla
"Reel sobre…", "carrusel de…", "post para Instagram/TikTok", guiones, ganchos, captions.

## Antes
Funda los datos con `pbm-evidencia` (aunque sea social, los datos deben ser reales). Regla 5: bienestar. Coordina con `content-creator-agent` si se necesita calendario o estética.

## REELS — estructura 2-Reel obligatoria
```
REEL 1 — EL PROBLEMA (impacto + credibilidad)
  Hook 3s: dato científico chocante (real)
  Desarrollo: el problema (CEM / luz azul / déficit) con estudio
  Cliffhanger: "pero hay algo que lo revierte… (parte 2)"
REEL 2 — LA SOLUCIÓN (profundidad)
  Recap 3s → mecanismo (CcO/mitocondria) → protocolo con panel → resultado esperable (bienestar) → CTA
```
Formato salida: GUION por escenas (segundo · texto en pantalla · voz en off · b-roll sugerido) + CAPTION + hashtags + CTA.

## CARRUSELES — método Fede Cabral (10 slides)
```
1  Hook irresistible (dato/pregunta disruptiva)
2-8 Profundidad educativa (mecanismo, evidencia, datos, 1 idea/slide)
9  Protocolo práctico con Ekio
10 CTA + sinergias
```
Formato salida: texto por slide + nota visual + caption + hashtags.

## POSTS
Hook + 1 idea científica + microhistoria/dato + CTA. Caption con 1-2 fuentes integradas.

## Estilo
Hook en 3s, una idea por bloque, lenguaje visual, autoridad + emoción. Datos reales SIEMPRE (la credibilidad es el activo). Nunca claim médico.

## Checks
- [ ] Hook real y verificable.  [ ] 1 idea por slide/escena.  [ ] CTA claro.
- [ ] Bienestar (Regla 5).  [ ] Nexo CEM o MTC si suma.
